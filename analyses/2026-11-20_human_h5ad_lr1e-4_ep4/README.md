## Исправления 20.11

1. **Калибровка ранг → экспрессия.** `build_human_h5ads.py` (и основной пайплайн скрипок, `c2s-puma-std/grid/lib/scan_only.py`)
   загружали `c2s-puma-std/grid/tree/retrain_v2/analysis/reports/rank_expr_model.npz` от 5.11 — подгонку под K = 800
   (наклон −0,6121, сдвиг 5,5417, r² 0,8361). Модель новой сетки выдаёт до 2000 генов, поэтому ранги 801–2000 ложились
   на продолжение прямой. Подгонка под K = 2000 сохранена в `reports/rank_expr_model_k2000.npz`
   (`c2s-puma-std/grid/lib/fit_calibration_k2000.py`: `fit_from_csv`, k = 2000, 2000 клеток, сид 0;
   наклон −0,6136, сдвиг 5,5459, r² 0,8665 — та же, что строит `results/2026-11-19_ali_he22_corrected_analysis/run_corrected_analysis.py`).
   Сборщик проверяет `k` в npz. Величина ошибки: модельные значения в h5ad сдвинулись не больше чем на 0,0066 (log1p),
   реальные не изменились.
2. **Имена генов.** Сборщик переименовывал гены по-своему (точка → дефис), а рукопись — `load_data.remap_gene_names`
   (`ALIAS_TO_CANONICAL`) с `real_counts._reindex_to_model_genes`. 19 столбцов CSV ложились не в те гены
   (SARS→SARS1, H3F3A→H3-3A, RPL30→RPL30L2, гистоны и др.), из-за этого сдвигалась обрезка до top-2000 и таблица
   спасённых генов давала 9 996 вместо 9 988. Теперь используются функции рукописи; таблица 9 988 = 9 988.
3. **Без CSV.** `build_human_h5ads.py --real-from <папка>` берёт реальные клетки из прежних h5ad (от калибровки они
   не зависят). После исправления 2 сборка один раз читала CSV; дальше cameraPR и анализ берут данные только из h5ad.

Команды сборки:
```
python3 build_human_h5ads.py --out-dir h5ad_calib_k2000            # из CSV, ~4 мин
python3 build_human_h5ads.py --out-dir <папка> --real-from h5ad_calib_k2000   # реальные клетки из h5ad, ~20 с
```

## 1. Анализ по скиллам (`scripts/scrna_skill_pipeline.py`)

```
python3 scripts/scrna_skill_pipeline.py --h5ad-dir h5ad_calib_k2000 --out-root h5ad_calib_k2000 \
    --seed 42 --n-top-genes 2000 --n-pcs 50 --n-neighbors 15 --resolution 0.5
```
- **QC** функциями single-cell-rna-qc (`calculate_qc_metrics`, `detect_outliers_mad`), пороги скилла:
  число генов 5 MAD, доля митохондриальных 3 MAD + 8 %. Метрики из полного слоя CPM (сырых каунтов в h5ad нет).
  Фильтруются только реальные клетки, по образцу (донору); модельные — сгенерированные списки, их не фильтруем.
  Убрано 8–20 % клеток на донора, в основном по митохондриальным.
- scanpy: 2000 вариабельных генов, PCA 50, соседи 15, UMAP, Leiden 0,5; маркеры типов — по реальному контролю.
- **DE** в каждом типе: Уилкоксон (`rank_genes_groups`, tie_correct), поправка Бенджамини–Хохберга, гены в ≥ 10 %
  клеток одной из групп; значимый ген: padj < 0,05 и |log2FC| ≥ 0,25. Тест — Boslaugh, гл. 13, с. 308–312;
  поправка — Benjamini & Hochberg 1995 (в книгах её нет).

## 2. cameraPR рукописи по трём сравнениям (`scripts/camerapr_azi_noazi.py`)

